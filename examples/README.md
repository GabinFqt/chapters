# Chapters examples

Copy what you need into the instance. The [wiki](https://github.com/GabinFqt/chapters/wiki) walks through the same ideas one case at a time.

## KubeJS

Copy [`kubejs/server_scripts/`](kubejs/server_scripts/) into the instance `kubejs/server_scripts/`.

[`main.js`](kubejs/server_scripts/main.js) defines test stages at load (`chapters:script_pickups`, `chapters:script_vanilla_all`). Grant one with `/chapters add <player> <stage>`.

[`ftbquests_chapter_reward.js`](kubejs/server_scripts/ftbquests_chapter_reward.js) is a Custom Reward for when the built-in FTB Quests Stage Reward is not enough.

## Datapack

Copy [`datapack/tutorial/`](datapack/tutorial/) into `saves/<world>/datapacks/`, enable it, then `/reload`.

Stage ids: `tutorial:intro_nether`, `tutorial:intro_dims`, `tutorial:tier_early`, `tutorial:tier_mid`, `tutorial:tier_late`, `tutorial:fluides_base`, `tutorial:recipe_pickaxe`, `tutorial:granular_emerald`.
